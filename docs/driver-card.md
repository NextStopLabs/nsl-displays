# Driver cheat sheet (print for cab)

```
SELECT DESTINATION:  type code (1-8 digits), ENTER confirms - 8-digit codes auto-select on 8th digit
CORRECT A DIGIT:     BACKSPACE (one digit) / DELETE or ESC (clear all)
BAD CODE:            board flashes INVALID - nothing changes, retype
NEXT STOP:           [+]   PREV STOP: [-]
ANNOUNCE NEXT STOP:  [*]   CLEAR OVERRIDE: [/]
UPDATE MODE:         [.]   (join hotspot 5 min - turn hotspot on first)
VOLUME:              keypad map or local UI / portal
```

State resumes after power loss (program/service/destination/stop/override/volume).
